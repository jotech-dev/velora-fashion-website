# VELORA — Fashion Website Concept

A premium fashion website concept designed and developed
as part of the JOTECH Digital Studio portfolio.

## About the Project

VELORA is a fictional fashion brand created to demonstrate
modern website design and frontend development skills.

The design focuses on elegance, simplicity, and a premium
fashion experience.

## Features

- Responsive layout for desktop and mobile
- Mobile navigation menu
- Fashion collection showcase
- Brand story section
- Contact section
- Interactive newsletter demo form
- Responsive images and typography

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.

## Project Status

Portfolio concept project.

The newsletter form does not send or store email addresses.
The website does not currently include real shopping,
payments, or order processing.
